# FUTURE_PE_02 – AI UGC Ad Content Generator

## Project Overview

This project was created as part of the Future Interns Prompt Engineering Internship.

The goal of this task was to build AI-powered prompts that generate engaging UGC-style ad content for social media marketing campaigns.

The project focuses on creating authentic, conversion-focused ad scripts and content suitable for Instagram Reels, Shorts, and modern beauty marketing.

## Business Chosen

GlowUp Beauty Salon, Mumbai

## What This Project Includes

* UGC ad hooks
* Instagram Reel scripts
* CTA-based ad content
* Social media captions
* Cinematic reel concepts

## Tools Used

* ChatGPT
* GitHub

## Skills Demonstrated

* Prompt Engineering
* UGC Ad Copywriting
* Social Media Marketing
* AI Content Generation
* Conversion-Focused Writing
* Creative Marketing Strategy

## Outcome

This project demonstrates how AI can be used to generate engaging UGC-style marketing content for real businesses using structured prompts and modern content marketing strategies.
